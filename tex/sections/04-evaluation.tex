\section{Evaluation}
\label{sec:eval}

\subsection{Experimental Setup}
\label{subsec:setup}

We evaluate Open-Sora v1.2 STDiT3-XL/2 using the 240p, 9:16,
51-frame, 30-step generation setting and report VBench for generation
quality. Quantized inference uses W8A8 GEMM/attention and FP16 vector
operations. The accelerator is synthesized in TSMC 28\,nm at 1\,GHz,
and performance is evaluated using cycle-level simulation. For comparison
with ViDA~\cite{ding2025vida}, we report technology-normalized 7-nm
results at the same 1\,GHz frequency and 256\,GB/s memory bandwidth.

\subsection{Algorithm Quality}
\label{subsec:quality}

Fig.~\ref{fig:quality_visual} presents representative generated videos.
QAC preserves the visual content of the high-precision and quantized
baselines while enabling more timestep reuse. Table~\ref{tab:quality}
reports the quantitative comparison using VBench and cache ratio.

Compared with naive Cache+Quant, QAC aligns the reuse decision with the
quantized execution trajectory, improving cache reuse at comparable
generation quality. Since DARE only changes the execution of recomputed
operators, it does not alter the generated output and is evaluated
separately below.
